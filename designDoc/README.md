# 设计文档索引

本目录存放 AI 流式对话项目的功能说明与设计文档，便于团队理解各模块职责与实现细节。

## 文档列表

| 文档 | 说明 |
|------|------|
| [功能设计文档.md](./功能设计文档.md) | 项目概述、系统架构、功能模块设计（含各功能结构与实现方法）、验收标准等 |
| [API接口文档.md](./API接口文档.md) | 后端 API 接口规范：请求/响应格式、错误码、示例 |
| [前端设计说明.md](./前端设计说明.md) | React 前端各目录与文件的功能说明、设计要点及数据流 |
| [后端设计说明.md](./后端设计说明.md) | Node.js 后端各目录与文件的功能说明与设计要点 |

## 阅读顺序建议

1. **新人/产品**：先读《功能设计文档》了解业务与架构，再按需查阅 API 或前后端设计说明。
2. **前端开发**：功能设计 → 前端设计说明 → API 接口文档（对接时）。
3. **后端开发**：功能设计 → 后端设计说明 → API 接口文档。
